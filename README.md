# Defencreation - Website

A fully responsive, frontend-only MVP website for Defencreation, a cybersecurity startup focused on protecting Indian teenagers online.

## 🚀 Features

- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern Design**: Clean, minimal UI with blue/green color theme
- **Smooth Animations**: Fade-in effects, hover animations, and scroll effects
- **Sticky Navigation**: Easy navigation across all pages
- **No Backend Required**: Pure HTML, CSS, and JavaScript

## 📁 Project Structure

```
├── index.html              # Home page
├── about.html              # About Us page
├── surakshithnet.html      # SurakshithNet App page
├── yuvamitra.html          # YuvaMitra App page
├── solutions.html          # Institutional Solutions page
├── contact.html            # Contact page
├── css/
│   └── style.css          # Main stylesheet
├── js/
│   └── script.js          # JavaScript functionality
└── README.md              # This file
```

## 🚀 How to Use

1. **Open the website**: Simply open `index.html` in any modern web browser
2. **Navigate**: Use the navigation menu to explore different pages
3. **Mobile View**: Resize your browser or open on mobile to see responsive design
4. **Contact Form**: Fill out the form on the contact page (data is logged to console)

## 🔧 Customization

### Colors
Edit the CSS variables in `css/style.css`:
```css
:root {
    --primary-color: #4A90E2;
    --secondary-color: #2ECC71;
    /* ... other colors */
}
```

### Content
- Edit HTML files directly to change text content
- Replace placeholder SVGs with actual images
- Update contact information in `contact.html`

### Functionality
- Modify `js/script.js` to add new interactive features
- Contact form can be connected to backend services like Formspree, EmailJS, etc.

## 📝 Notes
